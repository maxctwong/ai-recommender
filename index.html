AI Cloud-based Steam Games Recommender

Mission and Business Use Case

  • Help gamers make smarter game choices using review-driven intelligence
  • Surface authentic player insights based on real experience and not popularity or sales data

Data Engineering and Host

  • Use SteamDB to fetch all game names and ID
  • Use SteamWeb API to obtain structured metadata of games
  • Use AWS RDS to store the structured game metadata
  • Use AWS DynamoDB to store the user reviews for each game

Frontend and Backend

  • Create a website with Python Flask
  • Designed the backend to connect with AWS RDS and DynamoDB to suggest purchase decisions

Cloud Infrastructure

  • Set up virtual private cloud, security groups for EC2 instance and RDS, and 4 subnets (2 public and 2 private)
  • Configure EC2 instance
  • Populate RDS and local DynamoDB
  • Set up an AWS S3 bucket to store all raw data and code
  • Used AWS Lambda function to stop the instance periodically for webpage and database maintenance purposes

Financial Estimation

  • Calculate the cost of services across different cloud platforms (AWS, Google Cloud Platform, and Microsoft Azure)
  • Set up performance metrics and expectations
